The method — rank correlation, agreement-in-value p-values & Fisher combination ▾

Kendall's τb+ rank correlation

To test whether the measured G-values correlate with the predicted values, we use a modified Kendall's \(\tau_b\) — a rank-correlation coefficient that counts concordant pairs (both predicted and observed agree on ordering) minus discordant pairs, normalised by the total pairs corrected for ties. We call our variant \(\tau_b^+\) to flag one deliberate departure from the standard convention, explained below.

\[ \tau_b^+ = \frac{C - D + T_{XY}}{\sqrt{(C + D + T_X + T_{XY}) \times (C + D + T_Y + T_{XY})}} \]

Significance testing does not use \(\tau_b^+\) directly. Its exact asymptotic variance under this particular tie structure has no clean closed form, and deriving one honestly would be genuinely messy and complicated, without being any more trustworthy than the alternative below. Instead we get a conservative p-value using the simple, well-known variance of tau-a (exact when there are no ties) applied to a deliberately cautious stand-in value: the next higher tau-a.

Only the \(T = T_X + T_Y\) exclusive ties are still "ambiguous" here — joint ties (\(T_{XY}\)) are already resolved into \(C\) above, so they play no part in this step. Each exclusive tied pair could in principle have gone concordant or discordant; we search over every way the group of \(T\) ties could have shifted the numerator, and take the smallest shift whose resulting tau-a value is still strictly greater than \(\tau_b^+\):

\[ \tau_a^{\text{next}} \;=\; \min_{k} \left\{ \frac{S+k}{P} \; : \; \frac{S+k}{P} > \tau_b^+ \right\}, \quad k \in \{T, T-2, T-4, \dots\} \]

where \(S = C - D\). That value is then used with the simple tau-a standard deviation:

\[ z = \frac{\tau_a^{\text{next}}}{\sqrt{\dfrac{2(2n+5)}{9n(n-1)}}} \]

This is conservative by construction: since \(\tau_a^{\text{next}}\) is chosen as the closest tau-a value that still exceeds \(\tau_b^+\) — not the true, generally larger, worst-case tau-a — it never makes the result look more significant than it is. When there are no exclusive ties (\(T=0\)), \(\tau_a^{\text{next}} = \tau_b^+\) and this reduces to the direct formula. The page shows both values side by side ("τ-b+: … / τ-a: …") whenever they differ, so the number actually feeding \(z\) is never hidden.

\(C\) = number of concordant pairs, including joint ties (see below)

\(D\) = number of discordant pairs — pairs where the ordering disagrees

\(T_X\) = pairs tied on predicted value only  ·  \(T_Y\) = pairs tied on observed value only

\(T_{XY}\) = "joint ties" — pairs tied on both predicted and observed value

\(S = C - D\)  ·  \(P\) = total pairs \(= C+D+T_X+T_Y+T_{XY} = n(n-1)/2\)

\(n\) = number of selected measurements

The p-value is right-tailed, computed from the normal CDF of \(z\). Ties arise from measurement uncertainty, not from fundamental degeneracy.

On \(\tau_b^+\) vs. standard \(\tau_b\): standard tau-b drops a pair tied on both predicted and observed value entirely — it contributes to neither \(C\), \(D\), \(T_X\), nor \(T_Y\). Here, such a "joint tie" is instead counted as concordant, added to \(C\) and to \(T_{XY}\) — \(T_X\) and \(T_Y\) stay pure exclusive tie-counts, unaffected. Two different experiments independently landing on the same predicted and observed value is treated as supporting evidence, not as an uninformative pair. Keeping \(T_{XY}\) out of \(T_X\) and \(T_Y\) (rather than also inflating them) keeps the denominator large enough that perfect agreement can never push \(\tau_b^+\) above 1. This affects exactly two pairs in the default dataset — De Boer (1987) & Lamporesi (2008) and Goldblum (1987) & Ritter (1990).

A second, independent check: agreement in value

Separately from the rank-correlation test above, each measurement also carries its own p-value from a different method: for a given predicted value, count how many possible observed values — at the same decimal precision as the actual observation, across the 6.666–6.676 null range used throughout this dataset — agree with the prediction at least as well as the actual observation does, then divide by the total count of possible values in that range. This is not defined for observations falling outside the 6.666–6.676 range, so not every measurement has one.

There are actually two different, independent p-values computed per measurement, and it matters which null hypothesis each one tests against:

Range-based p-value (above) — null hypothesis: big-G could be any value at all ("no-pattern" null). It only asks how unusual the observed value is among all possible values in the 6.666–6.676 range, independent of any specific rival theory.

Comparative p-value — null hypothesis: the predecessor theory, i.e. Newtonian/GR gravity, using the CODATA-recommended value \(G_{\mathrm{GR}} = 6.6743 \pm 0.00015\). This directly asks how much more likely the observation is under SPD than under GR, rather than how unusual it is in the abstract.

The comparative p-value is obtained by computing a chi-square value for each theory's prediction against the same observation:

\[ \chi^2_{\mathrm{theory}} = \frac{(G_{\mathrm{obs}} - G_{\mathrm{pred,\,theory}})^2}{\sigma_{\mathrm{obs}}^2 + \sigma_{\mathrm{pred,\,theory}}^2} \]

then converting the difference between the two chi-square values into a likelihood-ratio "improvement" \(I\), and from that into a p-value:

\[ I = \exp\!\left(\frac{\chi^2_{\mathrm{GR}} - \chi^2_{\mathrm{SPD}}}{2}\right), \qquad p_{\mathrm{comp}} = \frac{1}{1+I} \]

Because the comparative method only needs a GR-side chi-square rather than the observation falling inside the 6.666–6.676 range, it is available for a much wider set of measurements than the range-based p-value — not just freefall/interferometer measurements with observed values far outside that range, but also the low-precision historic and modern measurements (Cavendish 1798 through Baldi 2001, plus the small-SD-but-out-of-range group) that never qualified for a range-based p-value at all. Range-based p-values tend to sit closer to the middle of the 0–1 interval, since they don't depend on standard deviations at all; comparative p-values can swing to much more extreme values (very close to 0 or to 1) when one theory's predicted uncertainty is far tighter than the other's.

Combining p-values with Fisher's method

Both kinds of per-measurement p-values are combined the same way, with Fisher's method, across whichever selected measurements carry one:

\[ \chi^2 = -2 \sum_{i=1}^{k} \ln(p_i) \]

where \(k\) is the number of measurements combined (not necessarily the full selected count \(n\), since some measurements fall outside the range/method each is defined over). \(\chi^2\) is tested against a chi-square distribution with \(2k\) degrees of freedom. Because those degrees of freedom are always even, the combined p-value has an exact closed form rather than needing a numerical approximation:

\[ p = e^{-\chi^2/2} \sum_{i=0}^{k-1} \frac{(\chi^2/2)^i}{i!} \]

The results are shown as two second, independent p-values alongside the rank-correlation statistics in the dashboard above — one range-based, one comparative against GR.
